How to Contribute to Your Basket

Help us build the most comprehensive, open seasonal produce database! You can contribute new vegetables, fruits, herbs, nuts, and roots, refine regional seasonality calendars, or submit high-quality photography.

Steps to Contribute

  1. Fork or clone the repository on GitHub: https://github.com/MelkiSch/your-basket
  2. Gather produce data: You will need to specify geographic regions, botanical Latin name, 52-week harvest/peak timeline, nutritional facts, storage tips, culinary pairings, and a high-resolution public photo.
  3. Add your produce entry to app.js / dataset.js using the JSON format below.
  4. Submit a Pull Request or open an issue on GitHub with your data!
